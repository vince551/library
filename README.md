# AMG Library — Frontend

This repository contains the AMG Library React + Vite frontend, preserving the original AMG visual system, page structure, navigation, learner-facing views, News & Events, Library Cards and Librarian Desk.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Frontend-only demo
The app uses in-memory demonstration data and simulated interactions. It does not connect to Firebase, Firestore, Firebase Storage, Laravel APIs or any production backend. Changes made during a session are temporary and reset on reload. The original AMG image assets are referenced from the public AMG repository.
